LumiPilot 데이터 처리 안내
문서 버전: 2026-10-29.1
권리자 표시명: LumiPilot
개인정보·데이터 처리 문의: lumipilothelp@gmail.com
적용: 이 문서 버전이 들어 있는 릴리스를 게시한 날부터 적용합니다. 운영자: 개인 개발자(표시명 LumiPilot). 안내 내용이 바뀌면 문서 버전을 올리고 다시 확인을 받습니다. 이 안내는 법률 자문이 아닙니다.

1. 기기 안에 저장하는 자료
앱 데이터 기본 위치: Windows는 %APPDATA%\LumiPilot\LumiPilot, Android는 /sdcard/Android/data/com.claude.claude_app/files/LumiPilot
아래 경로는 이 데이터 위치 기준입니다.
대화·도구 결과 등 세션 자료: data/sessions 아래 JSON·WAL 및 관련 파일
사용 전 안내 확인 기록: data/legal_notice_receipt.json. 확인한 문서 버전·언어·전문·UTC 시각을 기기에 저장하며, 개인정보 처리에 대한 포괄 동의나 도구 실행 허가로 취급하지 않습니다. 안내 내용이 바뀌면 다시 확인합니다.
첨부·생성 결과·메모리·설정·예약 작업 등도 기능에 따라 기기 안에 저장됩니다. 사용자 코드·도구가 지정한 외부 경로에는 별도의 파일이 생길 수 있습니다.
내장 브라우저의 쿠키·로그인·웹 저장소: Windows는 %LOCALAPPDATA%\LumiPilot\LumiPilot\WebView2, Android는 앱 전용 내부 저장소
실행 로그: data/log/app.log 및 회전 로그. 현재 파일당 8MiB를 기준으로 회전하며 메시지 한 건의 크기 등에 따라 실제 크기가 달라질 수 있습니다.
크래시 자료: data/CrashLogs. Windows 덤프에는 메모리에 있던 대화·파일·자격증명 등 민감한 내용이 포함될 수 있으므로 공개 업로드하지 마세요.

2. API 키와 로그인 정보
API 키와 지원되는 OAuth·MCP 비밀 저장소는 별도 자격증명 저장 계층을 사용합니다. 암호화 저장에는 Windows는 사용자 계정의 DPAPI를, Android는 Android Keystore의 앱 전용 키를 사용합니다. API 키의 암호화 저장에 실패하면 평문으로 대신 저장하지 않습니다.
모든 대화·첨부·로그·일반 설정·사용자 파일이 암호화된다는 뜻은 아닙니다. 같은 사용자 권한으로 실행되는 프로그램, 복호화 후 메모리, 외부 프로그램의 별도 저장까지 보호하는 보안 경계가 아닙니다. 다른 기기·계정으로 복사한 자격증명은 다시 입력하거나 로그인해야 할 수 있습니다.

3. 모델에 보내는 정보
사용자가 선택한 AI 제공자 또는 설정한 서버로 요청이 전송됩니다. 요청에는 현재 질문뿐 아니라 시스템 지침, 이전 대화·요약, 첨부·이미지·화면, 읽은 파일·검색 결과·도구 결과 등이 기능과 컨텍스트 구성에 따라 포함될 수 있습니다. 자동 제목·압축·예약·캐릭터 기능도 설정과 실행 조건에 따라 모델을 호출할 수 있습니다.
Ollama·사용자 지정 서버도 설정 주소를 기준으로 하며, 로컬 서버 선택만으로 이후 웹·MCP·연동 도구의 외부 통신까지 차단되지는 않습니다.

4. 연동·도구·브라우저의 전송
웹 검색·페이지 읽기: 검색어·URL·요청 데이터가 검색 제공자와 대상 사이트에 전달될 수 있습니다.
Google 등 연동: 로그인·권한 범위와 도구 호출에 따라 조회 대상, 문서·메일·일정 내용, 수신자·첨부 등이 해당 서비스에 전달될 수 있습니다.
메일·메시지·Git push·업로드: 지정한 수신자·저장소·서버에 실제 데이터가 전송될 수 있습니다. 조회한 결과가 이후 모델 요청에 포함될 수도 있습니다.
MCP·사용자 지정 도구·셸: 설정한 서버·실행 프로그램이 인자·환경·파일 등에 접근하고 자체 네트워크 통신을 할 수 있습니다.
이미지 생성·음성·위치 기능: 사용한 기능에 따라 프롬프트·참조 이미지·발화 텍스트·음성·좌표 등 요청 자료가 해당 제공자에 전달될 수 있습니다.
위치 조회: 기기 위치(Windows 위치 서비스·Android 위치 권한)를 쓸 수 있고 AI가 위치가 필요하다고 판단해 도구를 호출할 때만 좌표를 읽어 모델 요청에 담습니다. 위치를 쓸 수 없거나 권한을 거부하면 위치를 조회하지 않으며 IP 주소로 대신 추정하지도 않습니다. 별도의 확인 창은 뜨지 않습니다.
모델 목록 조회: NVIDIA 또는 OpenCode 제공자를 쓰면 모델 한도 정보를 받으려고 공개 카탈로그 models.dev에 인증 없이 요청합니다. 요청에는 API 키·대화가 들어가지 않습니다.
내장 브라우저·HTML 미리보기: 방문 사이트와 외부 리소스 서버가 일반 웹 요청·쿠키 등을 처리할 수 있습니다.
Android 권한: 마이크(음성 입력)·위치(위치 기능)·모든 파일 접근(작업 폴더의 파일 도구)·알림을 요청할 수 있습니다. 각 권한은 해당 기능을 쓸 때 필요하며, Android 설정에서 거부·철회할 수 있습니다. 거부하면 그 기능을 쓸 수 없습니다.
모든 외부 요청에서 수신자는 사용자의 IP 주소를 볼 수 있습니다. 사용자의 승인 범위와 자동 실행 설정을 확인해 주세요. 기능별 해외 처리 여부·수신자의 보관·학습·삭제·요금은 실제 선택한 제공자·서버와 그 정책에 따라 달라집니다.

5. 개발자 수집과 진단 자료
기기 내 저장과 외부 AI·도구 전송은 구분해야 합니다. '개발자가 받지 않는다'는 말이 '외부로 전송되지 않는다'는 뜻은 아닙니다. 이 버전의 앱은 사용 통계·대화·오류·크래시 자료를 개발자에게 자동으로 보내지 않습니다. 개발자가 운영하는 서버로 연결하는 기능은 없고, 로그와 크래시 자료는 기기에만 저장됩니다. 새 버전 확인만 예외입니다. 앱을 켤 때 마지막 확인 후 20시간이 지났으면 개발자의 GitHub 배포 저장소(github.com/lumipilot/LumiPilot)의 공개 파일(latest.json) 하나를 내려받아 버전을 비교합니다. 대화·설정·식별자는 보내지 않지만, 모든 인터넷 요청처럼 GitHub는 요청한 IP 주소와 앱 이름·버전(User-Agent)을 볼 수 있습니다. 설정 > 앱 정보에서 끌 수 있으며, 끄면 '지금 확인'을 누를 때만 이 요청을 합니다. 내장 브라우저(WebView2)·운영체제·Android 음성 인식 서비스 등은 제공자가 자체적으로 정보를 수집할 수 있으며 해당 제공자의 정책을 따릅니다.
신고용 로그·덤프를 보낼 때에는 수신자·목적·포함 내용·보존 기간을 먼저 확인해 주세요. 로그의 비밀 마스킹이 모든 개인정보를 제거한다고 보장하지 않습니다. API 키·대화·파일·메일·화면 내용을 직접 검토하고 필요한 범위만 전달해 주세요.
지원 이메일로 문의하면 발신 이메일 주소·표시 이름·문의 본문과 직접 첨부한 자료가 메일 서비스에 전달되고 운영자에게 접수됩니다. 지원 메일 처리는 앱의 로컬 저장·AI 제공자 전송과 별개입니다. 문의 확인·답변·문제 재현에 필요한 정보만 보내 주세요. 다른 사람의 개인정보나 민감한 파일을 보내기 전에 제공 권한과 필요성을 확인해 주세요.
지원 문의 자료는 문의 확인·답변·문제 재현에만 이용하며, 보낸 자료라는 이유로 목적 외 이용이나 무기한 보관을 하지 않습니다. 운영자(개인 개발자)가 문의 처리에 필요한 기간 동안 보관하고, 처리가 끝나 더 이상 필요하지 않으면 법령상 보존 사유가 없는 한 삭제합니다. 삭제를 원하시면 같은 메일 주소로 요청해 주세요. 요청을 확인한 뒤 법령상 보존이 필요한 자료를 제외하고 삭제합니다. 지원 메일은 Google의 Gmail로 받으므로 Google이 메일을 처리하며 미국 등 국외의 서버에 저장할 수 있습니다. Google의 처리와 보관은 Google 개인정보처리방침(https://policies.google.com/privacy)을 확인해 주세요.

6. 보관·삭제·이전
대화·첨부·설정은 기능별 삭제 또는 사용자 정리 전까지 남을 수 있습니다. 로그·첨부·스냅샷에는 기능별 용량 정리가 있지만 날짜 기준 일괄 자동 삭제나 완전 삭제를 보장하지 않습니다.
앱에서 세션 삭제 등 해당 기능을 사용하세요. 전체 로컬 자료를 지우려면 Windows는 앱과 관련 프로세스를 종료하고 필요한 자료를 백업한 뒤 위의 앱 데이터·내장 브라우저 폴더를 정리할 수 있습니다. Android는 앱을 제거하면 앱 데이터 폴더도 함께 지워지므로, 남길 자료는 제거 전에 백업해 주세요. 앱이 수정한 작업 폴더, 백업·동기화 사본과 외부 서비스의 자료는 별도로 관리해야 합니다.
파일 삭제는 저장 매체의 복구 불가능한 보안 삭제와 다릅니다. 외부 제공자에게 이미 전달된 자료는 앱의 로컬 삭제만으로 지워지지 않습니다. 해당 제공자의 삭제·로그아웃·토큰 철회 기능을 사용해 주세요.
운영자는 지원 문의 처리가 끝나 더 이상 필요하지 않거나 삭제 요청을 확인하면, 법령상 보존이 필요한 자료를 제외하고 운영자가 관리하는 해당 메일과 첨부파일을 삭제합니다. Gmail에서 삭제한 메일은 휴지통에 최대 30일 남을 수 있으며 휴지통에서 영구 삭제할 수 있습니다. Google의 백업이나 법령상 보존에 관한 처리에는 Google의 정책이 적용될 수 있습니다.

7. 처리 관계와 문의
개발자·이용자·외부 제공자가 개인정보처리자 또는 수탁자인지는 실제 처리 목적·결정 권한·계약·데이터 흐름에 따라 정해집니다. 사용자 기기에 저장되거나 사용자 API 키로 전송된다는 이유만으로 어느 한쪽의 의무가 항상 없어지는 것은 아닙니다.
국외 처리가 생길 수 있는 경로는 사용자가 고른 AI 제공자·서버·연동 서비스·MCP, models.dev 모델 목록 조회, GitHub 업데이트 확인, Gmail 지원 메일 등입니다. GitHub 업데이트 확인에는 IP 주소와 앱 이름·버전이 전달될 수 있고, GitHub가 자체 정책(https://docs.github.com/site-policy/privacy-policies/github-general-privacy-statement)에 따라 처리합니다. models.dev 요청과 선택한 서비스에 전달되는 항목은 3~5절을 참고해 주세요. 제공자별 수신자·국가·보관 기간은 해당 제공자의 정책을 확인해야 합니다. 업데이트 확인은 설정에서 끌 수 있고, 다른 전송은 해당 기능·제공자를 사용하지 않거나 지원 메일을 보내지 않는 방법으로 피할 수 있습니다. 이 경우 해당 기능을 쓰거나 문의 답변을 받을 수 없습니다.
